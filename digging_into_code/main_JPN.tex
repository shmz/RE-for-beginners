\chapter{コード内の重要/興味深いものを見つける}

ミニマリズムは現代のソフトウェアの顕著な特徴ではありません。

\myindex{\Cpp!STL}

しかし、プログラマーがたくさん書いているからではなく、多くのライブラリが一般的に実行可能ファイルに静的にリンクされているためです。
すべての外部ライブラリが外部DLLファイルに移行すれば、世界は違っていたでしょう。
（C++のもう一つの理由は\ac{STL}やその他のテンプレートライブラリです。）

\newcommand{\FOOTNOTEBOOST}{\footnote{\url{http://go.yurichev.com/17036}}}
\newcommand{\FOOTNOTELIBPNG}{\footnote{\url{http://go.yurichev.com/17037}}}

したがって、関数の起源を判断することは非常に重要です。それが標準ライブラリや
よく知られたライブラリ（Boost\FOOTNOTEBOOST、libpng\FOOTNOTELIBPNGなど）からのものか、
またはコード内で見つけようとしているものに関連しているかを判断することです。

探しているものを見つけるために\CCppのすべてのコードを書き直すことは、全くばかげています。
