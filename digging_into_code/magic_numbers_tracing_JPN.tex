\mysection{トレース中のマジックナンバーの使用}

多くの場合、私たちの主要な目標は、ファイルから読み取られたか、ネットワーク経由で受信された値をプログラムがどのように使用するかを理解することです。
値の手動トレースは、しばしば非常に労働集約的なタスクです。これに対する最も簡単な技術の一つ（100％信頼できるわけではありませんが）は、独自の\IT{マジックナンバー}を使用することです。

これは、ある意味でX線コンピューター断層撮影に似ています：放射線造影剤が患者の血液に注入され、
X線で患者の内部構造の可視性を向上させるために使用されます。
健康な人間の血液が腎臓でどのように浸透するかはよく知られており、薬剤が血液中にあれば、断層撮影で血液がどのように浸透し、
結石や腫瘍があるかどうかを簡単に見ることができます。

\TT{0x0badf00d}のような32ビット数字、または\TT{0x11101979}のような誰かの誕生日を取り、
調査するプログラムで使用されるファイル内のある点にこの4バイト数字を書き込むことができます。

\myindex{\GrepUsage}
\myindex{tracer}

次に、\tracerを\IT{コードカバレッジ}モードでこのプログラムをトレースしながら、\IT{grep}の助けを借りて
またはテキストファイル（トレース結果の）で検索するだけで、値がどこで使用され、どのように使用されたかを簡単に見ることができます。
