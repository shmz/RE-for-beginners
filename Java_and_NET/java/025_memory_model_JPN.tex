\subsection{\ac{JVM}メモリモデル}

x86および他の低レベル環境では、引数の受け渡しとローカル変数の格納にスタックを使用します。

\ac{JVM}は少し異なります。

次のものがあります：

\begin{itemize}
\item ローカル変数配列（\ac{LVA}）。
入力関数引数とローカル変数の格納として使用されます。

\INS{iload\_0}のような命令がそこから値をロードします。

\INS{istore}はそこに値を格納します。
最初に関数引数が格納されます：0から始まるか、1から始まります
（0番目の引数が\IT{this}ポインタによって占有されている場合）。

その後、ローカル変数が割り当てられます。

各スロットのサイズは32ビットです。

したがって、\IT{long}と\IT{double}データ型の値は2つのスロットを占有します。

\item オペランドスタック（または単に「スタック」）。
計算や他の関数を呼び出す際の引数の受け渡しに使用されます。

x86のような低レベル環境とは異なり、明示的に値をプッシュまたはポップする
命令を使用せずにスタックにアクセスすることはできません。

\item ヒープ。オブジェクトと配列の格納として使用されます。

\end{itemize}

これら3つの領域は互いに分離されています。
